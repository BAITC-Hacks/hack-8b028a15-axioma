# Решение для Astana Hub

Название: Axioma — объяснимое пополнение склада

Описание:
Axioma — сервис закупок для Электрокомплект: Excel/ZIP → прогноз → объяснимый заказ → проверка менеджером → Excel. Учитывает сезонность, рост, отсутствие товара, разовые покупки, остатки, даты поступлений, MOQ и кратность. Проверяет запас по дням: поздняя поставка не скрывает промежуточный дефицит; отдельно показывает потребность для ускорения. Общая ML-модель и статистические методы сопоставлены со средним на 3045 товарах за июнь–август; результаты и ограничения опубликованы. В демо — 11 воспроизводимых проверок пяти обязательных требований с числами до/после. 82 локальных теста, импорт всех 12 файлов компании проверен. Утверждения сбрасываются при изменении расчёта; корзина по поставщикам сохраняет проверившего и параметры. Неизвестные остатки и сценарии явно отмечены. README, методология, протокол проверки и трёхминутная защита — в репозитории. Локальное демо без API-ключей. Денежная экономия пока не доказана.
