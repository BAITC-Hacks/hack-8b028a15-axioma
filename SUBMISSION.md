# Карточка решения для Astana Hub

Название: **Axioma — объяснимое пополнение склада**

Описание для карточки:

Axioma помогает закупщику Электрокомплект получить из Excel/ZIP проверяемый заказ поставщику. Сервис отделяет разовые покупки, учитывает сезонность, рост, подтверждённое отсутствие, остатки и даты поступлений, минимум и кратность. Промежуточный дефицит виден по дням. Менеджер проверяет количество и сохраняет утверждение вместе с исходным расчётом, ответственным и причиной изменения. Заказы разных поставщиков объединяются в общую корзину и экспортируются в Excel. Неизвестный остаток не подменяется нулём; сценарии явно отмечены.

Проверены все 12 XLSX. Историческое сравнение семи методов: 3045 товаров за март–август 2026. Основной режим уменьшил среднюю WAPE по товарам относительно среднего за шесть месяцев на 3,22% для IEK и 6,08% для Systeme Electric. Это диагностика разработки, а не независимое доказательство будущей точности или экономии. Некоторые товары лучше прогнозируются другими методами. 130 автоматических тестов, 11 примеров требований, локальное демо без API-ключей и воспроизводимый протокол входят в репозиторий.
