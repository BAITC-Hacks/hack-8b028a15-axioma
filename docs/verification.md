# Проверка на Windows

23 сентября 2026. Python 3.12, Streamlit 1.64.0, Pandas 3.0.1, NumPy 2.3.5, OpenPyXL 3.1.5, pytest 9.1.1.

`python -m pytest -q`: 22 теста пройдены. Проверены арифметика заказа, MOQ/кратность, известные периоды отсутствия, сезонность, прирост категории, переданный коэффициент поставщика, выбросы накладных и клиента за день, сохранение повторяющихся крупных покупок, неполный месяц, будущие данные, заполнение недостающей месячной истории без двойного счёта, неизвестные остатки, даты поставок, импорт ZIP, отбрасывание служебной строки MOQ и запуск интерфейса.

В браузере проверены синтетический пример, вкладка объяснения с графиком и загрузка локальных файлов Systeme Electric. На реальных данных Systeme Electric: 724 товара, 497 известных текущих остатков, 227 позиций без остатка, 71 положительная рекомендация при стандартных настройках на 23.09.2026. Это результат расчёта, не утверждённый заказ и не доказательство точности прогноза.

Все 12 XLSX прочитаны. По IEK актуальный свободный остаток отсутствует; сервис требует ввод/CSV перед расчётом количества заказа. Нет обезличенного ID клиента и точных stockout-периодов: соответствующие механизмы проверены на синтетических данных. Экономический эффект и точность на отложенной реальной выборке не измерены.

Дополнительная проверка архивов воспроизводится командой `python verify_real.py "IEK.zip" "Systeme electric.zip"`. Коммерческие исходники остаются локально и не включены в репозиторий.
