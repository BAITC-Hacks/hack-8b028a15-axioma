# Протокол проверки рабочего места закупщика — 23.09.2026

## Локальные воспроизводимые проверки

Среда: macOS, Python 3.14, Streamlit 1.64.0, Pandas 3.0.6, NumPy 2.5.3. `python -m pytest -q`: **103 теста пройдены** (9,82 с на этом ноутбуке). Включены обе сохранённые реализации команды. `python -m pip check`: конфликтов зависимостей нет. `git diff --check`: ошибок нет. Предупреждение joblib о физических ядрах приводит к использованию логических ядер и не останавливает расчёт.

К существовавшим 82 проверкам добавлены 21:

- 16 сценарных проверок: все варианты требуют пополнения; уточнение остатка переключает да/нет; задержка создаёт промежуточный дефицит или меняет заказ; неизвестный остаток не становится нулём; будущие данные исключены; отсутствие истории; устойчивое «не заказывать»; спрос не выдаётся за влияние остатка; порядок очереди; совпадение с основным расчётом; путь без даты/просроченный; три проверки границ параметров.
- 4 проверки основного интерфейса: задержка и ручной пересчёт; происхождение решения в утверждённом XLSX; открытие товара без истории; загрузка XLSX → неопределённость → пересчёт → утверждённый Excel.
- 1 регрессия: нулевой прогноз с коэффициентом роста поставщика не вызывает ошибку типа NumPy и не создаёт спрос.

Сохранены и проходят проверки разовой продажи (`test_invoice_spike_is_robust`) и повторяющегося крупного клиента (`test_recurring_large_customer_is_not_deleted_as_one_off`). Это синтетические тесты корректности, не наблюдаемый экономический эффект. В AppTest действия редактора таблицы и возврат загрузчика эмулируются, поскольку его API не поддерживает эти операции; чтение и запись XLSX выполняются настоящими Pandas/OpenPyXL.

## Полные реальные наборы

Шесть XLSX каждого поставщика. Дата 23.09.2026, новая поставка 21 день, пересмотр 14, страховой запас 7, общая ML-модель, рост из сводки выключен. Сетка: остаток/спрос ±20%, известные будущие поступления +0/+7 дней. Текущие остатки не заменялись глобальным сценарием снимка.

Проверены уникальность и полнота SKU, неотрицательные конечные количества, MOQ/кратность, совпадение диапазона со всеми строками сетки и совпадение исходного варианта задержки с основным расчётом. IEK: 0 оценённых позиций в отдельном эксперименте означает **нет актуальных остатков**, а не отсутствие риска. Сценарная сетка по снимкам при этом доступна для части товаров, но не разрешает безусловное утверждение.

Продолжительность одного локального запуска с импортом и расчётом: 11,65 с / 53,19 с. Это не нагрузочный тест. Исходные коммерческие данные не опубликованы. Сохранены только [агрегаты проверки](decision-checks.json).
