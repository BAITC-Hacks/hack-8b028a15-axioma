# Проверка качества 23 сентября 2026

Проверены все 3045 товаров с минимум шестью месяцами истории до июня: 582 Systeme Electric и 2463 IEK. Три последовательных месяца проверки — июнь–август 2026. Перед каждым прогнозом история обрезается до начала целевого месяца. Готовые коэффициенты роста, сезонность поставщика и ретроспективные периоды отсутствия исключены из проверки. Код: `src/validation.py`; агрегаты: `benchmark-systeme.json`, `benchmark-iek.json`.

| Поставщик | Проверено SKU | С положительными продажами | Обычное среднее | Исходная эвристика | Автовыбор | Общая ML-модель |
|---|---:|---:|---:|---:|---:|---:|
| Systeme Electric | 582 | 430 | 105,24% | 190,89% | 119,63% | 104,39% |
| IEK | 2463 | 1493 | 140,61% | 222,98% | 129,35% | 133,07% |

Значения — среднее по SKU от WAPE каждого товара за три месяца. Меньше — лучше; ошибки выше 100% возможны. Метры и штуки не складываются в общий знаменатель. Общая ML-модель снижает эту ошибку относительно среднего на 0,81% у Systeme Electric и 5,36% у IEK. Автовыбор у IEK лучше общей модели, но у Systeme Electric хуже простого среднего. Универсального победителя нет.

1122 товара имеют нулевой суммарный факт и исключены из процентной метрики, но не из проверки. Среди них положительный прогноз хотя бы в одном месяце дали: Systeme Electric — среднее 78, эвристика 78, автовыбор 75, ML 78 из 152; IEK — соответственно 326, 326, 328, 326 из 970. Защита ML не допускает возобновления спроса только за счёт общего положительного смещения после шести месяцев без положительного скорректированного спроса. Это не означает, что все прогнозы для нулевого факта устранены.

Это воспроизводимая ретроспективная проверка, а не независимая финальная оценка: небольшие подмножества этих данных использовались при разработке, полные результаты также просматривались. Для независимого подтверждения нужен новый период. Мы не заявляем доказанную экономию, статистическую значимость или гарантированное преимущество на будущих данных.

Наблюдаемые продажи включают разовые заказы и могут быть ограничены отсутствием товара. Метрика не измеряет точность именно регулярного спроса или экономию запасов. Для этого нужны размеченные проектные продажи, ежедневная доступность и цены/стоимость дефицита.

Регрессионные тесты проверяют выбросы, сохранение повторяющихся крупных покупок известных клиентов, компенсацию отсутствия, сроки транзита, MOQ/кратность, сценарные остатки, корзину и отсутствие влияния будущих данных на прошлый прогноз. Отсутствующая запись целевого месяца пропускается; пустые ячейки исходной месячной таблицы считаются нулём — допущение импорта.

Команды полного воспроизведения:

```bash
python scripts/validate_history.py --folder "/путь/к/IEK" --supplier IEK --limit 5000 --pooled
python scripts/validate_history.py --folder "/путь/к/Systeme electric" --supplier "Systeme Electric" --limit 5000 --pooled
```

Исходные коммерческие файлы остаются локально; опубликованы только агрегаты.
