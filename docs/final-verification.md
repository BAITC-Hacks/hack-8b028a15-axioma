# Проверка финальной доработки — 23.09.2026

Среда: macOS, Python 3.14; Streamlit 1.64.0, Pandas 3.0.6, NumPy 2.5.3, OpenPyXL 3.1.5, scikit-learn 1.9.1, pytest 9.1.1.

## Автоматические проверки

`python -m pytest -q`: 82 теста пройдены. Включены обе реализации команды, прежние регрессии и новые проверки промежуточного дефицита, отделения срочного объёма, округления по кратности, сценария утверждения с проверившим и сброса отметок после изменения расчёта. Проверка приложения использует Streamlit AppTest; редактирование таблицы в тесте эмулируется, поскольку AppTest не предоставляет API редактирования data_editor.

`python -m pip check`: конфликтов установленных зависимостей нет. `git diff --check`: ошибок пробелов нет. Предупреждение joblib об определении физических ядер в ограниченной среде не остановило расчёт; используется число логических ядер.

В браузере проверен чистый запуск `app.py`, открыта вкладка «Проверка кейса»: 11 из 11 синтетических проверок пройдены, отображаются результаты и кнопка скачивания протокола.

## Полные реальные наборы

Все шесть XLSX каждого поставщика загружены с локального диска. Настройки: дата 23.09.2026, новая поставка 21 день, пересмотр 14 дней, страховой запас 7 дней, общая ML-модель, рост из сводки выключен. Проверены уникальность SKU, количество выходных строк, неотрицательность количества, MOQ/кратность и запрет безусловного заказа при неизвестном остатке.

| Поставщик | Товаров | Строк детализации | Известный остаток | Положительных рекомендаций | Срочных позиций | Заказ неизвестен |
|---|---:|---:|---:|---:|---:|---:|
| IEK | 3184 | 171603 | 0 | 0 | 0 | 3184 |
| Systeme Electric | 724 | 77312 | 497 | 19 | 10 | 227 |

Локальная длительность импорта и расчёта: 45,90 с и 9,12 с соответственно. Это один замер на данном ноутбуке, не нагрузочный тест и не обещание скорости в иной среде. Сценарные остатки в этой проверке не применялись. Неизвестный заказ включает отсутствие остатка или истории; не все позиции без заказа являются дефицитными.

Историческая оценка прогноза не пересчитывалась: изменение дневного планирования заказов не меняет прогноз спроса. Сохранённые результаты и их ограничения: [validation.md](validation.md).
