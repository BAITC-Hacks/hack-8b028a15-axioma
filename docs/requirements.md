# Axioma — требования и исходные данные

Кейс Электрокомплект: автоматическое пополнение склада.

Обязательные функции: базовая потребность по SKU; сезонность и устойчивый рост; компенсация stockout; исключение разовых крупных продаж, включая продажи одному обезличенному клиенту; рекомендации по поставщикам с объяснением.

Прочитаны 12 Excel-файлов из IEK.zip и Systeme electric.zip. Подробная история: 171605 и 77314 строк с заголовками/итогами. Отрицательные количества сохраняются как корректировки. История 2024 берётся из месячных отчётов, подробные операции в основном покрывают 2025–2026. Нельзя суммировать два представления одних продаж.

В детализации нет идентификатора клиента. Номер документа используется только для группировки заказа. Поддержку client_id необходимо отдельно проверить на синтетическом наборе.

Остатки IEK — начало месяца; актуальный остаток на 22.09.2026 отсутствует. Systeme Electric содержит свободный остаток, резерв, категории, коэффициент роста и поставку 24.09. Месячные остатки не доказывают число дней stockout. Точные интервалы stockout принимаются отдельным входом.

Сроки поставки новых заказов отсутствуют: требуется редактируемый параметр с явной маркировкой допущения. Исходные коммерческие данные не публикуются вместе с кодом. Синтетический пример должен позволять эксперту запустить проект без архивов.
