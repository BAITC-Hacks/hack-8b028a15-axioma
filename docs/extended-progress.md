# История разработки AXIOMA

## 23.09.2026 — первый этап

Подготовлены архитектура, перечень обязательных функций и отчёт о структуре 12 Excel-файлов. Выявлены отсутствующий ID клиента, неполный месяц, возвраты и неодинаковая доступность актуальных остатков. Согласован сценарий менеджера и почасовой план.

На момент подготовки GitHub недоступен через Git без авторизации. Локальный commit не является подтверждением push; публикацию необходимо проверить отдельно.

## 23.09.2026 — реализация прототипа

Код перенесён в клон команды, созданный через GitHub Desktop. Подготовлены алгоритм, импортеры ZIP/CSV, интерфейс Streamlit, синтетические примеры, проверки, CSV/XLSX-экспорт с утверждением, инструкция запуска и сценарий демонстрации.

Первый полный прогон исходных архивов: 3 443 товара, 248 884 строки продаж, 313 строк поступлений; 70 положительных рекомендаций, 2 973 позиции требуют уточнения. Это результаты первого прогона, не обещание количества после последующих корректировок. Отрицательные продажи не превращаются в положительный спрос.

Проверками выявлена и исправлена ошибка смешения устойчивого роста с сезонностью: сезонные коэффициенты теперь оцениваются после удаления тренда. Добавлена сверка месячных сводок с детализацией и валидация дат/единиц.

Автоматический commit в клон пока блокируется правами среды на `.git/index.lock`. Команде предложен ручной Commit / Push в GitHub Desktop. Успешная удалённая публикация не подтверждена.

## 23.09.2026 — проверка ранней истории

Обнаружено отсутствие обычных продаж в ранних месяцах детализации при наличии месячных сводок за 2024 год. Старые возвраты больше не создают искусственные нулевые месяцы. Ранняя месячная история подключена к расчёту сезонности без двойного счёта. Добавлены соответствующие регрессионные тесты; итог — 24 прошедших теста. README содержит методику, ограничения и воспроизводимый сценарий проверки.

Файлы подготовлены к коммиту в клоне команды. Повторная стандартная попытка commit всё ещё блокируется средой на `.git/index.lock`; ожидается ручная публикация через GitHub Desktop.

Завершающий полный прогон двух архивов прошёл без исключений: 86 положительных рекомендаций, 2 973 заблокированных позиции, импорт 42.1 с, расчёт 139.2 с. Исправлена инвалидация кэша при обновлении алгоритма; UI-тест повторно прошёл. Подготовлен архив кода и синтетических данных для передачи команде.


## 23.09.2026 — подготовка объединения с командой

На предоставленных снимках GitHub подтверждены публикация ветки feature/axioma-local (b3c2774) и создание PR #1. При объединении main (b8985fc) обнаружены восемь конфликтов. Их содержимое согласовано: основное приложение команды app.py/src сохранено; дополнительная реализация перенесена в app_extended.py/axioma, её тесты получили отдельные имена. README описывает оба режима и различия методик. Правила Git исключают коммерческие файлы и разрешают только синтетические CSV в data/demo.

После изменения файлов полный локальный pytest: 46 passed in 14.89s. Маркеры конфликтов отсутствуют, git diff --check без ошибок. Индекс Git не изменялся агентом: завершение merge и включение новых файлов требуется выполнить в GitHub Desktop. Объединённая версия ещё не подтверждена на удалённом сервере.
