# Решение для Astana Hub

Название: Axioma — объяснимое пополнение склада

Описание:
Axioma — сервис закупок для Электрокомплект: Excel/ZIP → прогноз → объяснимый заказ → проверка менеджером → Excel. Общая ML-модель учится на истории разных товаров; доступны автовыбор методов для прерывистого спроса и обычное среднее. Сервис отделяет разовые крупные продажи, учитывает сезонность, остатки, даты поставок, минимальные партии и кратность. Показывает ожидаемую дату дефицита и объединяет одобренные позиции по поставщикам. Проверка на 3045 товарах IEK и Systeme Electric за июнь–август: средняя по товарам WAPE общей модели ниже обычного среднего на 5,36% и 0,81% соответственно. Это ретроспективная проверка; экономия и преимущество на будущих данных не доказаны. Недостающие остатки, ID клиентов и периоды отсутствия явно отмечены. Локальное демо без API-ключей, методология, тесты и сценарий защиты — в репозитории.
