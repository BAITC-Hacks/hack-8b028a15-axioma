## Как обновлять проект командой

1. Сохранить свои изменения коммитом в своей ветке. Не заменять всю папку
   чужой копией и не выполнять принудительный push.
2. Перед новой правкой обновить `main` через Fetch / Pull и создать свою ветку.
3. Стили менять в `assets/axioma-ui.css`; блок расчётов ради оформления
   не редактировать. В pull request включать только файлы своей задачи.
4. Перед объединением подтянуть актуальную `main` в рабочую ветку, проверить
   конфликтующие участки по содержимому и запустить существующие тесты.
   Отдельный CSS уменьшает пересечение правок, но не гарантирует отсутствие
   конфликтов при одновременном изменении одного участка.
5. После Pull остановить ранее запущенный Streamlit (`Ctrl+C` в его терминале)
   и запустить заново по README. Затем обновить вкладку браузера. Если изменился
   `requirements.txt`, сначала обновить зависимости по README.
