# Проверка версии с оценкой эффекта — 23.09.2026

## Реализовано

В существующем `app.py` добавлена «Проверка эффекта»: три неизменённых алгоритма прогноза, общий симулятор запасов, потерянная продажа и отложенный заказ, одинаковые исходные условия, проигранные случаи, дневной баланс и ZIP протокола. Сценарные затраты требуют ввода ставок и источника; денежные результаты на данных компании не заявлены. Подготовлены пустые задания пилота с чередованием Excel/Axioma. Основной сценарий и работа команды сохранены.

## Что закрыто и что осталось

**Закрыто:** раньше не было воспроизводимого сравнения решений по запасам и явного списка проигрышей; теперь они есть. Можно проверить баланс, воспроизвести любой заказ симуляции и оценить сценарные затраты при собственных ставках. Есть измеримый план работы с закупщиком.

**Не закрыто и не замаскировано:** превосходство ML, денежная экономия и реальное внедрение. Новая симуляция показывает худший средний немедленный сервис ML относительно простого среднего на обеих выборках. Июнь–август уже использовались, месячный факт равномерно распределён по дням, физический начальный запас задан сценарием. Для дальнейшего улучшения нужен новый период, подтверждённые ежедневные остатки/резервы и приходы, спрос при отсутствии, ID клиентов, согласованные ставки и участие закупщика.

См. [карту доказательств и протокол пилота](pilot.md). Карточка Astana Hub в этом проходе не отправляется: пользователь просит отдельное разрешение.
